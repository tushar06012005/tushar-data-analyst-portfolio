# Tushar Sangwan - Data Analyst Portfolio

## How to open
1. Extract the ZIP completely.
2. Double-click `START_PORTFOLIO.bat`.
3. Your browser will open the portfolio at http://localhost:8000/index.html.
4. Keep the command window open while using the portfolio.
5. Resume and SoftPrax certificate links work through the local server.

If `python` is not installed, install Python 3 and make sure "Add Python to PATH" is enabled, then run the BAT again.
